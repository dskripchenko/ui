# Полоса вех

`UidMilestoneStrip` показывает несколько вех (лучше всего читается три–пять) на шкале месяцев: названия месяцев сверху, по строке на веху с ромбом на её дате, подпись и пояснение рядом и, по желанию, вертикальная линия «сегодня». Это дорожная карта одним взглядом, а не диаграмма Ганта: длительностей нет, только даты.

```vue
<script setup lang="ts">
import { UidMilestoneStrip, type Milestone } from '@dskripchenko/ui'

const items: Milestone[] = [
  { key: 'design', label: 'Дизайн утверждён', date: '2026-09-12', caption: 'Готово' },
  { key: 'beta', label: 'Публичная бета', date: '2026-10-20', caption: 'Два блокера', risk: true },
  { key: 'docs', label: 'Документация', date: '2026-11-18', caption: 'По плану' },
  { key: 'release', label: 'Релиз 2.0', date: '2026-12-15', caption: 'Запланирован', href: '/releases/2.0' },
]

function open(item: Milestone) {
  // показать подробности вехи
}
</script>

<template>
  <UidMilestoneStrip
    :items="items"
    today="2026-11-10"
    today-label="Сегодня, 10 ноября"
    @select="open"
  />
</template>
```

## Props

| Prop | Тип | По умолчанию | |
|---|---|---|---|
| `items` | `Milestone[]` | — | `{ key, label, date, caption?, risk?, href? }`; `date` — `YYYY-MM-DD`. |
| `start` | `string` | первый день самого раннего месяца | `YYYY-MM-DD`, первый день шкалы. Самый ранний месяц берётся по вехам и `today`. |
| `end` | `string` | последний день самого позднего месяца | `YYYY-MM-DD`, последний день шкалы (включительно). |
| `today` | `string` | — | `YYYY-MM-DD`: вертикальная линия 2 px цвета danger через все строки. |
| `todayLabel` | `string` | — | Сноска под полосой с короткой меткой того же цвета. Не задавайте, если поясняете линию своей разметкой. |
| `monthFormat` | `'short' \| 'long'` | `'short'` | Названия месяцев в шапке — ровно как их даёт `Intl.DateTimeFormat` для локали (`окт.` / `октябрь`, `Oct` / `October`). |
| `ariaLabel` | `string` | из локали («Вехи») | Доступное имя списка. |

Событие `select(item: Milestone)` — активирована веха без `href` (щелчок, Enter или пробел). Веха с `href` — обычная ссылка `<a :href>` и ничего не испускает. Слотов нет.

## Раскладка

- Положение вехи — начало её дня на шкале: `(date − start) / (end − start + 1)`. Даты вне шкалы прижимаются к краям.
- Названия месяцев стоят на первом дне каждого месяца; неполный первый месяц (свой `start`) подписывается, только если он достаточно широк.
- Строка не ниже 44 px, под ней тонкая линия. Ромб — квадрат 12 px, повёрнутый на 45°, рамка 2 px цвета `--uid-accent`, без заливки; `risk` делает рамку `--uid-warning`, а пояснение — `--uid-color-warning-text`.
- Подпись (14 px, полужирный) и пояснение (12 px, вторичный цвет) стоят справа от ромба. Начиная с 70 % ширины они уходят влево от него и выравниваются вправо, чтобы не выходить за край. Длинные подписи переносятся — на 390 px ждите две строки.
- Где линия «сегодня» пересекает текст, под текстом лежит `--uid-milestone-surface` (по умолчанию `--uid-color-surface`): задайте ему фон, на котором стоит полоса.

CSS-переменные: `--uid-milestone-marker`, `--uid-milestone-risk`, `--uid-milestone-today`, `--uid-milestone-surface`, `--uid-milestone-row-h`. Используются только токены темы, поэтому светлая и тёмная темы работают сразу.

## Доступность

- Вехи — нумерованный список (`<ol>`) с именем из `ariaLabel`; шапка месяцев и линия «сегодня» декоративны (`aria-hidden`).
- Каждая веха — ссылка или кнопка с именем «подпись, дата, пояснение» (дата прописью для локали: `20 октября 2026 г.`), а для `risk` — ещё `milestoneStrip.atRisk` из локали («под угрозой»).
- Вехи в порядке табуляции и показывают кольцо фокуса набора.

Ключи локали: `milestoneStrip.label`, `milestoneStrip.atRisk`. Типы: `UidMilestoneStripProps`, `UidMilestoneStripMonthFormat`, `Milestone`.
