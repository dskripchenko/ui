# QR-код

`UidQrCode` рисует QR-код одним SVG. Кодировщик входит в библиотеку (без зависимостей) и следует ISO/IEC 18004: числовой, буквенно-цифровой и байтовый режимы (текст — в UTF-8), версии 1–40, уровни коррекции L, M, Q и H, маска с наименьшим штрафом. Берётся самая маленькая версия, в которую текст помещается на выбранном уровне; код пересчитывается при каждом изменении `value`.

```vue
<script setup lang="ts">
import { UidQrCode } from '@dskripchenko/ui'

const uri = 'otpauth://totp/Example:alice@example.com?secret=JBSWY3DPEHPK3PXP&issuer=Example'
</script>

<template>
  <UidQrCode :value="uri" label="Отсканируйте приложением-аутентификатором" />
</template>
```

## Пропсы

| Пропс | Тип | По умолчанию | |
|---|---|---|---|
| `value` | `string` | — | Что закодировать: URL, URI `otpauth://`, любая строка. |
| `size` | `number` | `176` | Ширина и высота, px. |
| `errorCorrection` | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` | Какую часть кода можно повредить, а он всё равно прочитается: около 7 %, 15 %, 25 % и 30 %. Чем выше уровень, тем больше версия для того же текста. |
| `margin` | `number` | `4` | Свободное поле вокруг кода, в модулях. Стандарт требует четыре; меньше — только если код и так стоит на широком светлом фоне. |
| `label` | `string` | `label` из локали | Доступное имя (`role="img"` + `aria-label`). |

## События

| Событие | Данные | |
|---|---|---|
| `error` | `Error` | Значение не помещается в код версии 40 на этом уровне. Компонент тогда показывает только светлый квадрат. |

Ёмкость самого большого кода в байтах: 2953 на L, 2331 на M, 1663 на Q, 1273 на H. Кириллическая буква в UTF-8 занимает два байта, иероглиф — три.

## Отрисовка

В SVG один `<rect>` для фона (вместе со свободным полем) и один `<path>` со всеми тёмными модулями, `shape-rendering="crispEdges"`, поэтому код резкий при любом размере и уменьшается по `max-width: 100%`. Для надёжного чтения дайте модулю хотя бы 2–3 px: код версии 7 (45 модулей плюс поле) хорошо читается при стандартных 176 px.

## Оформление

| Переменная | По умолчанию | |
|---|---|---|
| `--uid-qr-code-dark` | `--uid-color-zinc-950` | Тёмные модули. |
| `--uid-qr-code-light` | `--uid-color-white` | Фон и свободное поле. |

В тёмной теме цвета те же: сканерам нужны тёмные модули на светлом фоне, а инвертированный код многие не читают. Если меняете цвета, сохраняйте сильный контраст и тёмный цвет у модулей.

## Кодировщик

Кодировщик экспортируется и для работы без компонента — на сервере, на canvas, в тестах.

```ts
import { encodeQr } from '@dskripchenko/ui'

const { version, size, modules, mask } = encodeQr('https://example.com/', { errorCorrection: 'Q' })
// modules[row][column] — true для тёмного модуля; свободного поля в массиве нет.
```

| Опция | Тип | По умолчанию | |
|---|---|---|---|
| `errorCorrection` | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` | Уровень коррекции. |
| `minVersion` | `number` | `1` | Наименьшая версия, 1–40. |
| `mask` | `number` | — | Задать маску 0–7 вместо маски с наименьшим штрафом. |

Результат — `QrCode`: `version`, `size` (17 + 4 × версия), `modules`, `errorCorrection` и `mask`. Если текст не помещается в версию 40 на этом уровне, `encodeQr` бросает `RangeError` с числом байтов или символов.

Типы: `UidQrCodeProps`, `QrCode`, `QrEncodeOptions`, `QrErrorCorrection`.

## Тексты

Подпись по умолчанию — из словаря локали, раздел `qrCode` (см. [i18n](./i18n.md)): `label`.
