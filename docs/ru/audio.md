# Аудио

`UidAudio` — аудиоплеер на нативном элементе `<audio>`: компактная строка (воспроизведение, полоса перемотки, время, громкость, скорость), вариант `mini` для таблиц и списков, волновая форма, вычисляемая в браузере, и плейлист. Контроллер у него общий с [UidVideo](./video.md).

```vue
<UidAudio src="/media/episode.mp3" title="Episode 12" artist="The Podcast" waveform />

<UidAudio :src="row.recording" variant="mini" />

<UidAudio v-model:index="current" :tracks="playlist" waveform />
```

| Prop | Тип | По умолчанию | |
|---|---|---|---|
| `src`, `type` | `string` | — | Один трек; с `type` неподдерживаемый формат сообщается сразу |
| `title`, `artist` | `string` | — | Показываются над полосой перемотки |
| `tracks` | `UidAudioTrack[]` | — | Плейлист: `{ src, type?, title?, artist?, peaks?, duration? }` |
| `index` (`v-model:index`) | `number` | `0` | Текущий трек плейлиста |
| `variant` | `'default' \| 'mini'` | `'default'` | `mini` — одна строка: воспроизведение, полоса, время |
| `waveform` | `boolean` | `false` | Волновая форма, декодированная в браузере, в роли полосы перемотки |
| `peaks` | `number[]` | — | Заранее вычисленные пики `0..1`; волна рисуется без декодирования |
| `waveformMaxBytes` | `number` | 40 МБ | Файлы больше не декодируются — вместо волны обычная полоса |
| `waveformMaxDuration` | `number` | 1800 | Более длинное аудио (в секундах) не декодируется |
| `autoAdvance` | `boolean` | `true` | Следующий трек плейлиста по окончании текущего |
| `loop` | `boolean` | `false` | Повтор трека или всего плейлиста |
| `preload` | `'none' \| 'metadata' \| 'auto'` | `'metadata'` | |
| `crossorigin` | `'' \| 'anonymous' \| 'use-credentials'` | — | |
| `exclusive` | `boolean` | `true` | Запуск этого плеера ставит на паузу остальные |
| `resumeKey` | `string` | — | Запоминает позицию (для каждого трека плейлиста) |
| `rates` | `number[]` | `0.5…2` | Меню скорости |
| `hotkeys` | `boolean` | `true` | Пробел/`K`, стрелки, `J`/`L`, `M`, `0`–`9`; `Shift+N` / `Shift+P` — следующий / предыдущий трек |
| `showVolume`, `showRate` | `boolean` | `true` | |
| `showPlaylist` | `boolean` | `true` | Список треков под плеером |

События: `play`, `pause`, `ended`, `error`, `trackchange` (индекс), `update:index`. Наружу отдаются: `play()`, `pause()`, `toggle()`, `seek()`, `next()`, `prev()`, `state`, `media`.

## Раскладка

- **Обычный** — строка: кнопка воспроизведения, название и полоса перемотки, время, громкость, скорость. В узком контейнере (меньше 480 px) полоса перемотки переносится на отдельную строку во всю ширину, название и исполнитель встают друг под другом, ползунок громкости уступает место аппаратным кнопкам. Начиная с 560 px ползунок громкости виден всегда.
- **Mini** — по умолчанию шириной `240px` (`--uid-audio-mini-width`), помещается в ячейку таблицы: воспроизведение, полоса или маленькая волна, время (до воспроизведения — длительность, во время — позиция). Запуск одной строки ставит на паузу остальные.
- **Плейлист** — «предыдущий» / «следующий» по бокам от кнопки воспроизведения и нумерованный список с отмеченным играющим треком. «Предыдущий» сначала перематывает в начало трек, который играет дольше 3 секунд. Экран блокировки и аппаратные медиаклавиши работают через Media Session API.

## Волновая форма

С `waveform` файл загружается и декодируется через Web Audio (`decodeAudioData` с низкой частотой дискретизации, чтобы экономить память), а пики считаются порциями, между которыми управление отдаётся браузеру (`requestIdleCallback`, иначе `setTimeout`). Результаты кешируются по адресу на время жизни страницы; файлы декодируются по одному и только когда плеер близко к видимой области, так что таблица из сотни записей остаётся отзывчивой. Файлы больше `waveformMaxBytes` или длиннее `waveformMaxDuration` остаются с обычной полосой. Аудио должно быть доступно для `fetch` — тот же источник или CORS.

Для длинных записей считайте пики на сервере и передавайте их в `peaks` (любой длины; плеер пересэмплирует их под свою ширину):

```ts
import { computePeaks } from '@dskripchenko/ui'

// например, в воркере или при обработке загрузки
const peaks = await computePeaks([audioBuffer.getChannelData(0)], 512)
```

Хелперы: `getWaveform(src, options)`, `computePeaks(channels, count)`, `resamplePeaks(peaks, n)`, `peaksToPath(peaks)`.

## Форматы

| Формат | Chrome / Edge | Firefox | Safari macOS | Safari iOS |
|---|---|---|---|---|
| MP3 | ✓ | ✓ | ✓ | ✓ |
| AAC / M4A | ✓ | ✓ | ✓ | ✓ |
| Ogg · Opus | ✓ | ✓ | ✓ (свежие версии) | ✓ (свежие версии) |
| Ogg · Vorbis | ✓ | ✓ | свежие версии | свежие версии |
| WAV (PCM) | ✓ | ✓ | ✓ | ✓ |
| FLAC | ✓ | ✓ | ✓ | ✓ |
| WebM · Opus | ✓ | ✓ | ✓ | ✓ (свежие версии) |

Проверено в реальных браузерах (Playwright): MP3, Ogg/Opus, WAV, FLAC и M4A воспроизводятся и рисуют волну в Chromium 156, Chrome 156 и WebKit 27. Для менее распространённого формата лучше указывать `type`: плеер сообщит «не поддерживается» сразу, а не после неудачной загрузки.
