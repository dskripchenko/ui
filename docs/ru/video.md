# Видео

`UidVideo` — видеоплеер на нативном элементе `<video>` с собственными элементами управления кита: полоса перемотки с буферизованными участками, главами и превью кадров, громкость, меню скорости и качества, субтитры, полноэкранный режим и «картинка в картинке». Без зависимостей; HLS-потоки воспроизводит отдельная лениво загружаемая точка входа (`@dskripchenko/ui/hls`).

```vue
<UidVideo
  src="/media/lesson.mp4"
  poster="/media/lesson.jpg"
  :tracks="[
    { src: '/media/lesson.en.vtt', srclang: 'en', label: 'English', default: true },
    { src: '/media/lesson.chapters.vtt', kind: 'chapters' },
  ]"
  thumbnails="/media/lesson.thumbs.vtt"
  resume-key="lesson-42"
/>
```

| Prop | Тип | По умолчанию | |
|---|---|---|---|
| `src` | `string` | — | Один источник |
| `sources` | `UidMediaSource[]` | — | `{ src, type?, label? }` в порядке предпочтения; браузер берёт первый, который умеет воспроизвести. Два и больше с `label` образуют меню качества |
| `poster` | `string` | — | Картинка до начала воспроизведения |
| `tracks` | `UidMediaTrack[]` | `[]` | WebVTT: `{ src, kind?: 'subtitles' \| 'captions' \| 'chapters', srclang?, label?, default? }` |
| `thumbnails` | `string` | — | WebVTT, реплики которого указывают на тайлы спрайта: `sprite.jpg#xywh=0,0,160,90` |
| `autoplay` | `boolean` | `false` | Запускается без звука как можно раньше (браузеры блокируют автовоспроизведение со звуком) |
| `muted`, `loop` | `boolean` | `false` | |
| `preload` | `'none' \| 'metadata' \| 'auto'` | `'metadata'` | |
| `controls` | `boolean` | `true` | `false` — голый элемент с элементами управления браузера |
| `crossorigin` | `'' \| 'anonymous' \| 'use-credentials'` | — | Нужен для субтитров и превью с другого источника |
| `exclusive` | `boolean` | `true` | Запуск этого плеера ставит на паузу остальные эксклюзивные плееры на странице |
| `resumeKey` | `string` | — | Запоминает позицию в `localStorage` и продолжает с неё |
| `rates` | `number[]` | `0.5…2` | Меню скорости |
| `hotkeys` | `boolean` | `true` | Горячие клавиши, пока плеер в фокусе |
| `aspectRatio` | `string` | `'16 / 9'` | Пропорции блока, пока размер видео неизвестен |
| `title` | `string` | — | Доступное имя плеера |
| `autoHide` | `number` | `2500` | Миллисекунды без активности, после которых элементы управления скрываются во время воспроизведения |
| `hlsOptions` | `HlsOptions` | — | Передаются HLS-адаптеру (см. ниже) |
| `hlsLoader` | `() => Promise<module>` | динамический импорт | Откуда берётся HLS-адаптер |

События: `play`, `pause`, `ended`, `error` (`{ kind, detail? }`), `qualitychange` (метка), `audiotrackchange` (метка). Компонент отдаёт наружу `play()`, `pause()`, `toggle()`, `seek(seconds)`, реактивный `state` и элемент `media`.

## Элементы управления

- **Полоса перемотки** — просмотренная часть акцентным цветом, буферизованные участки, промежутки между главами; при наведении показываются время, название главы и превью кадра. Перетаскивание перематывает сразу. Как `slider` она понимает стрелки (±5 с), Page Up/Down (±10 %), Home/End.
- **Громкость** — кнопка выключает звук, ползунок раскрывается при наведении или фокусе (на сенсорных экранах это делают аппаратные кнопки).
- **Настройки** — скорость и, если вариантов несколько, качество (`Авто` для HLS подстраивается под пропускную способность), а для HLS-потока с несколькими звуковыми дорожками — аудиодорожка. Меню живут внутри плеера, поэтому работают в полноэкранном режиме; в маленьком плеере они становятся шторкой поверх видео.
- **Субтитры** — кит рисует реплики сам (над элементами управления, читаемо на любом видео); в нативном полноэкранном режиме iOS их показывает системный плеер.
- **Узкий плеер** — панель следует ширине самого плеера: уже 440 px субтитры и «картинка в картинке» переезжают в меню настроек, уже 360 px время показывает только позицию. Воспроизведение, настройки и полный экран остаются всегда.
- **Полный экран** — на весь экран разворачивается весь плеер; на iPhone, где в полноэкранный режим может перейти только сам `<video>`, открывается нативный плеер.
- **Картинка в картинке** — стандартный API или режим презентации Safari.
- **Прямые трансляции** показывают вместо времени метку «Эфир»; на живом крае она становится красной, клик переносит туда.

На сенсорных экранах касание показывает или скрывает элементы управления, двойное касание по левой или правой трети перематывает на ∓10 с, центральная кнопка запускает и ставит на паузу. На десктопе клик по видео запускает/ставит на паузу, двойной клик переключает полноэкранный режим. Во время воспроизведения элементы управления скрываются через `autoHide` и остаются, пока открыто меню, перетаскивается полоса или фокус внутри них.

## Клавиатура

| Клавиша | Действие |
|---|---|
| Пробел, `K` | Воспроизведение / пауза |
| ← / → | −5 с / +5 с |
| `J` / `L` | −10 с / +10 с |
| ↑ / ↓ | Громкость ±10 % |
| `M` | Выключить звук |
| `F` | Полный экран |
| `C` | Субтитры вкл. / выкл. |
| `0`–`9` | Переход на 0–90 % |
| Home / End | Начало / конец |

## Ошибки

Ошибки показываются внутри плеера с кнопкой «Повторить» и имеют вид: `aborted`, `network`, `decode`, `unsupported`, `mse`, `manifest`, `encrypted`, `codec`, `unknown`. Тексты берутся из локали `media.errors` (см. [i18n](./i18n.md)). 404 сообщается как `network`, а не как «неподдерживаемый формат», как это делают браузеры. Если источник не воспроизводится, пробуется следующий из `sources`.

## Форматы

Что браузеры воспроизводят нативно (кит для этого ничего не добавляет):

| Формат | Chrome / Edge | Firefox | Safari macOS | Safari iOS |
|---|---|---|---|---|
| MP4 · H.264 + AAC | ✓ | ✓ | ✓ | ✓ |
| MP4 · HEVC | с аппаратным декодированием | Windows с аппаратным декодированием | ✓ | ✓ |
| WebM · VP9 + Opus | ✓ | ✓ | ✓ | ✓ (свежие версии) |
| MP4/WebM · AV1 | ✓ | ✓ | с аппаратным декодированием | с аппаратным декодированием |
| HLS (`.m3u8`) | через адаптер кита; свежие версии и нативно | через адаптер кита | нативно | нативно |

Проверено в реальных браузерах (Playwright): Chromium 156, Chrome 156, WebKit 27 — MP4 H.264/AAC, WebM VP9/Opus, HLS fMP4 и MPEG-TS (через адаптер и нативно), AES-128, живые плейлисты, разрывы, альтернативные звуковые дорожки (fMP4, MPEG-TS, packed AAC) с переключением. Firefox в тестовом окружении был недоступен.

## HLS

Источник с `type: 'application/x-mpegURL'` (или адресом `.m3u8`) воспроизводится через `@dskripchenko/ui/hls`. Адаптер — отдельная точка входа, которая загружается динамическим импортом только при появлении такого источника, — основной бандл не растёт.

- Там, где браузер воспроизводит HLS сам (Safari, iOS, свежий Chrome), адрес отдаётся прямо в `<video>` (`preferNative: true`; `false` — всегда использовать адаптер и получить меню качества).
- Иначе адаптер кормит Media Source Extensions: master- и media-плейлисты, сегменты **fMP4/CMAF** с `EXT-X-MAP`, сегменты **MPEG-TS** (H.264 + AAC), которые преобразуются в fMP4 в браузере, диапазоны байтов, `EXT-X-DISCONTINUITY`, **AES-128** (WebCrypto), **альтернативные звуковые дорожки** (`EXT-X-MEDIA TYPE=AUDIO` с URI) в собственном SourceBuffer, синхронные с видео при перемотке и смене качества; дорожка выбирается по `audioLanguage`, затем `DEFAULT`, затем `AUTOSELECT` на языке браузера и переключается в меню настроек; звуковые дорожки в fMP4, MPEG-TS или **packed AAC** с меткой времени в ID3; живые плейлисты с перезагрузкой и скользящим окном, буферизация вперёд и вытеснение, перемотка, ABR с ручным выбором качества, повторы с нарастающей задержкой.
- Не поддерживаются: SAMPLE-AES / DRM (ошибка `encrypted`), HEVC или MP3 внутри MPEG-TS (ошибка `codec`), части low-latency HLS.

```ts
import { UidVideo } from '@dskripchenko/ui'

// В шаблоне:
// <UidVideo src="https://cdn.example/live/master.m3u8" :hls-options="{ maxBufferAhead: 20 }" />
```

| `HlsOptions` | По умолчанию | |
|---|---|---|
| `preferNative` | `true` | Использовать встроенный HLS браузера, если он есть |
| `startLevel` | `-1` | Начальный вариант; `-1` — решает ABR |
| `audioLanguage` | — | Предпочтительный язык звуковой дорожки (`ru`, `en-US`…) |
| `maxBufferAhead` | `30` | Сколько секунд буферизовать вперёд |
| `maxBufferBehind` | `30` | Сколько секунд хранить позади позиции воспроизведения |
| `retries` | `3` | Повторы неудачного запроса (500 мс, 1 с, 2 с…) |
| `initialBandwidth` | `1000000` | Первая оценка пропускной способности, бит/с |
| `capToPlayerSize` | `true` | ABR не выбирает варианты намного выше плеера |
| `transmuxer` | встроенный MPEG-TS | Фабрика преобразователя сегментов; `null` отключает его |

Адаптер можно использовать без компонента:

```ts
import { attachHls } from '@dskripchenko/ui/hls'

const session = attachHls(videoElement, url, {
  onLevels: (levels) => console.log(levels.map((l) => l.label)),
  onError: (e) => console.warn(e.code, e.message),
})
session.setLevel(1)   // -1 — обратно в автоматический режим
session.setAudioTrack(1) // другая звуковая дорожка
session.stats()        // буферы по SourceBuffer, уровень, пропускная способность
session.destroy()
```

Преобразователь для другого контейнера подключается через `transmuxer`: объект с `canHandle(bytes)`, `push(bytes, { discontinuity })` → `{ init?, data, mimeType, tracks, startTime }` и `reset()`.

## Контроллер

`useMediaController(mediaRef, options)` — общее ядро обоих плееров; на нём можно собрать собственный интерфейс плеера.

```ts
const media = ref<HTMLVideoElement | null>(null)
const { state, play, pause, toggle, seek, skip, setVolume, toggleMute, setRate, toggleFullscreen, togglePip, handleKey } =
  useMediaController(media, { fullscreenTarget: rootRef, resumeKey: 'intro' })
```

`state` реактивен: `playing`, `paused`, `ended`, `waiting`, `stalled`, `seeking`, `currentTime`, `duration`, `live`, `buffered`, `volume`, `muted`, `rate`, `fullscreen`, `pip`, `error`. `handleKey(event)` применяет горячие клавиши выше и возвращает `true`, если клавиша обработана.

## Оформление

Элементы управления всегда светлые на тёмной подложке. Переменные: `--uid-video-accent` (просмотренная часть, отмеченные пункты), `--uid-video-radius`, `--uid-video-bg`, `--uid-video-caption-size`.
