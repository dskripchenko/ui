# Сетка дашборда

`UidDashboardGrid` раскладывает элементы по сетке из столбцов и строк — как виджеты на дашборде. Элемент стоит в столбце `x` и строке `y` (оба с нуля) и занимает `w` столбцов и `h` строк; высота сетки — по самому нижнему элементу. В режиме правки элементы перетаскиваются за ручку, которую рисует хост, меняют размер за угол, который рисует сама сетка, и двигаются с клавиатуры. Своей копии раскладки сетка не держит: после каждого завершённого жеста она отдаёт новый массив элементов (`v-model:items`), а хост его сохраняет.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { UidDashboardGrid, type DashboardGridItem } from '@dskripchenko/ui'

type Widget = DashboardGridItem & { title: string }

const editing = ref(false)
const items = ref<Widget[]>([
  { id: 'revenue', title: 'Выручка', x: 0, y: 0, w: 4, h: 2, minW: 2 },
  { id: 'orders', title: 'Заказы', x: 4, y: 0, w: 4, h: 2 },
  { id: 'traffic', title: 'Трафик', x: 8, y: 0, w: 4, h: 4, minH: 2 },
  { id: 'notes', title: 'Заметки', x: 0, y: 2, w: 8, h: 2, maxH: 3 },
])

function save(layout: DashboardGridItem[]): void {
  // сохранить позиции: один вызов на завершённое перетаскивание, изменение размера или нажатие клавиши
}
</script>

<template>
  <UidDashboardGrid
    v-model:items="items"
    :editable="editing"
    :item-label="(item) => (item as Widget).title"
    label="Обзор магазина"
    @change="save"
  >
    <template #item="{ item, editing: canEdit, handle }">
      <section class="widget">
        <header>
          <button v-if="canEdit" type="button" v-bind="handle">⠿</button>
          <h3>{{ (item as Widget).title }}</h3>
        </header>
        …
      </section>
    </template>
  </UidDashboardGrid>
</template>
```

## Элементы

| Поле | Тип | |
|---|---|---|
| `id` | `string \| number` | Идентификатор элемента. |
| `x`, `y` | `number` | Столбец и строка, с нуля. |
| `w`, `h` | `number` | Ширина в столбцах и высота в строках. |
| `minW`, `minH`, `maxW`, `maxH` | `number` | Пределы размера в клетках. Ширина не больше `columns`. |

У элементов могут быть любые другие поля: в отдаваемом массиве — объекты хоста с новыми `x`, `y`, `w`, `h`, остальное сохраняется.

## Правка

При `editable` хост привязывает `handle` к своему элементу-ручке — обычно к кнопке в заголовке элемента. Нажатие и движение указателя (мышь, перо или касание) поднимает элемент: он следует за указателем, чуть приподнятый, пунктирная заглушка «Отпустите здесь · 4 × 2» показывает клетку, куда он встанет, а остальные элементы расступаются. Отпускание ставит его на место; Escape во время перетаскивания отменяет его и возвращает раскладку. Уголок в правом нижнем углу каждого элемента так же меняет его размер.

Правила раскладки:

- позиции и размеры привязываются к целым клеткам и ограничиваются столбцами и `minW`…`maxH`;
- элемент, брошенный на другие, сдвигает их вниз; элемент, протащенный вниз мимо другого, меняется с ним местами;
- затем раскладка уплотняется по вертикали: каждый элемент всплывает вверх, насколько может, в порядке чтения (по строкам, затем по столбцам). Результат детерминирован и без наложений.

`update:items` и `change` срабатывают один раз на завершённый жест, с одним и тем же новым массивом, и только если что-то сдвинулось.

Без `editable` раскладка статична: `handle` — пустой объект, уголков нет, ничего не перетаскивается.

## Клавиатура

Ручка и уголок — фокусируемые кнопки.

| Клавиши | На ручке | На уголке |
|---|---|---|
| ←, →, ↑, ↓ | Сдвиг на одну клетку | Ширина или высота ± 1 |
| Shift + стрелки | Ширина или высота ± 1 | — |
| Escape | Отменить идущее перетаскивание указателем | Отменить идущее изменение размера |

Шаг вниз на одну строку, который «гравитация» вернула бы обратно, переносит элемент за нижнего соседа. После сдвига фокус остаётся на ручке. Каждое изменение объявляется через скрытую live-область («Выручка» перемещён: столбец 5, строка 1; «Выручка»: новый размер 6 × 3); в подписи ручки — позиция и размер элемента, скрытая подсказка объясняет клавиши.

## Узкий контейнер

Когда сама сетка уже `stackBelow` (по умолчанию 640 px; ширина измеряется `ResizeObserver`), элементы встают в один столбец в порядке чтения, каждый высотой `h × rowHeight`, и правка выключается (`editing` в слоте — `false`, `handle` пуст).

## Свойства

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `items` | `DashboardGridItem[]` | — | Раскладка; вместе с `v-model:items`. |
| `columns` | `number` | `12` | Число столбцов. |
| `rowHeight` | `number` | `80` | Высота строки, px. |
| `gap` | `number` | `16` | Зазор между клетками, px. |
| `editable` | `boolean` | `false` | Элементы можно двигать и менять размер. |
| `stackBelow` | `number` | `640` | Ширина контейнера, px, ниже которой элементы встают в один столбец. |
| `label` | `string` | `label` из локали | Доступное имя сетки. |
| `itemLabel` | `(item) => string` | «Элемент 3» | Имя элемента в подписях ручки и уголка и в объявлениях. |

## События

| Событие | Данные | |
|---|---|---|
| `update:items` | `DashboardGridItem[]` | Новый массив после броска, изменения размера или нажатия клавиши. |
| `change` | `DashboardGridItem[]` | Тот же массив; один раз на завершённый жест. |

## Слоты

| Слот | Свойства | |
|---|---|---|
| `item` | `{ item, editing, dragging, handle }` | Содержимое клетки. `editing` — сетка редактируемая и не в стопке; `dragging` — этот элемент сейчас тащат или меняют размер; `handle` — `DashboardGridHandleBindings` для `v-bind` на ручку. |
| `placeholder` | `{ w, h }` | Текст внутри заглушки. |

В `handle` — `onPointerdown`, `onKeydown`, `tabindex: 0`, `role: 'button'`, `aria-roledescription`, `aria-label`, `aria-describedby`, `aria-keyshortcuts` и `data-uid-grid-handle`. Сетка даёт ручке `cursor: grab` и `touch-action: none`.

Типы: `UidDashboardGridProps`, `DashboardGridItem`, `DashboardGridHandleBindings`, `DashboardGridItemSlotProps`.

## Функции раскладки

Правила выше — чистые функции, экспортируются для сервера или тестов. Каждая возвращает новые объекты в порядке входа и сохраняет лишние поля.

| Функция | |
|---|---|
| `collides(a, b)` | Пересекаются ли два элемента (сам с собой — никогда). |
| `clampItem(item, columns)` | Привязывает элемент к целым клеткам, его пределам и столбцам. |
| `compactLayout(items, columns)` | Вертикальное уплотнение с разрешением наложений. |
| `moveItem(items, id, x, y, columns)` | Сдвигает элемент, разрешает столкновения и уплотняет. |
| `resizeItem(items, id, w, h, columns)` | Меняет размер, сдвигает накрытое и уплотняет. |
| `layoutHeight(items)` | Сколько строк занимает раскладка. |
| `sortByPosition(items)` | Элементы в порядке чтения. |
| `sameLayout(a, b)` | Стоят ли все элементы двух раскладок на тех же клетках. |

## Оформление

У обёртки элемента нет своего оформления — карточку рисует содержимое хоста. Переменные: `--uid-dashboard-grid-placeholder-bg` и `--uid-dashboard-grid-placeholder-border` (по умолчанию — акцент). Переходы идут по `--uid-duration-base` и выключены при `prefers-reduced-motion`. Светлая и тёмная темы — из токенов темы.

## Тексты

Подписи берутся из словаря локали, раздел `dashboardGrid` (см. [i18n](./i18n.md)): `label`, `item(n)`, `handleRole`, `handle(title, x, y, w, h)`, `resize(title, w, h)`, `hint`, `dropHere(w, h)`, `moved(title, x, y)`, `resized(title, w, h)`, `cancelled(title)`. Столбцы и строки в текстах — с единицы.
