# Поле кода

`UidCodeInput` — поле для одноразового кода (подтверждение входа, код второго фактора, код из письма), который вводится в ряд отдельных ячеек. Ввод переводит фокус в следующую ячейку, Backspace — назад, а вставленный или автоматически подставленный код сразу раскладывается по ячейкам. Когда заполнены все ячейки, поле отдаёт событие `complete` — хост может проверить код без кнопки отправки.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { UidCodeInput } from '@dskripchenko/ui'

const code = ref('')
const invalid = ref(false)
const field = ref<InstanceType<typeof UidCodeInput> | null>(null)

async function verify(value: string): Promise<void> {
  invalid.value = !(await checkCode(value)) // ваш запрос
  if (invalid.value) {
    field.value?.clear()
    field.value?.focus()
  }
}
</script>

<template>
  <UidCodeInput
    ref="field"
    v-model="code"
    name="code"
    autofocus
    :invalid="invalid"
    @complete="verify"
  />
</template>
```

## Поведение

- Введённый символ заполняет ячейку, фокус переходит в следующую. Ввод в заполненную ячейку заменяет её символ; при фокусе содержимое ячейки выделяется.
- Backspace очищает ячейку; в пустой ячейке — очищает предыдущую и переходит в неё. Delete очищает ячейку на месте.
- ← и → двигают между ячейками, Home и End — к первой и последней.
- Вставка в любую ячейку или автозаполнение всего кода браузером раскладывает код по ячейкам с первой; пробелы, дефисы и символы, которые `mode` не допускает, отбрасываются, так что `123 456` и `12-34-56` дают `123456`. Код короче заполняет первые ячейки, остальные очищаются.
- В режиме `numeric` принимаются только цифры, а телефон показывает цифровую клавиатуру (`inputmode="numeric"`); в режиме `alphanumeric` — латинские буквы и цифры, буквы переводятся в верхний регистр.
- У первой ячейки `autocomplete="one-time-code"`: iOS и Android предлагают код, пришедший по SMS.

Значение — заполненные символы по порядку. `complete` срабатывает один раз на каждое новое полное значение: снова — если пользователь поменял символ в полном коде, и никогда — при установке `v-model` снаружи.

## Пропсы

| Пропс | Тип | По умолчанию | |
|---|---|---|---|
| `modelValue` | `string` | `''` | Код; используйте с `v-model`. Символы, которые `mode` не допускает, отбрасываются, остальное обрезается до `length`. |
| `length` | `number` | `6` | Число ячеек. |
| `mode` | `'numeric' \| 'alphanumeric'` | `'numeric'` | Какие символы принимают ячейки. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Размер ячейки: 36 × 44, 44 × 52 или 52 × 60 px. |
| `disabled` | `boolean` | `false` | Отключает все ячейки. |
| `invalid` | `boolean` | `false` | Оформление ошибки и `aria-invalid="true"` у каждой ячейки. |
| `autofocus` | `boolean` | `false` | Фокус в первую пустую ячейку при монтировании. |
| `name` | `string` | — | Имя скрытого поля со всем значением, чтобы обычная форма его отправила. У самих ячеек имени нет. |
| `label` | `string` | `label` из локали | Доступное имя группы. |
| `id` | `string` | — | id первой ячейки — для внешнего `<label for>`. |

## События

| Событие | Данные | |
|---|---|---|
| `update:modelValue` | `string` | После каждого изменения. |
| `complete` | `string` | Заполнены все ячейки. |

## Методы

Через ref в шаблоне: `focus()` ставит фокус в первую пустую ячейку (в последнюю, если код полный); `clear()` очищает все ячейки и обновляет `v-model`, фокус не трогает.

## Доступность

Ячейки собраны в `role="group"` с именем из `label` (по умолчанию «Код подтверждения»). Каждая ячейка — `<input>` с подписью «Символ 2 из 6». У ячейки в фокусе — рамка акцентного цвета и мягкое кольцо (цвет ошибки при `invalid`). Опишите код — откуда он, сколько символов — текстом рядом с полем и там же покажите сообщение об ошибке: `invalid` только окрашивает ячейки.

## Оформление

| Переменная | По умолчанию | |
|---|---|---|
| `--uid-code-input-cell-width` | `44px` | Ширина ячейки при `md`; если ряд не помещается, ячейки сужаются. |
| `--uid-code-input-cell-height` | `52px` | Высота ячейки при `md`. |
| `--uid-code-input-font-size` | `22px` | Размер символов при `md`. |
| `--uid-code-input-gap` | `--uid-space-sm` | Зазор между ячейками. |
| `--uid-code-input-font` | `--uid-font-family-mono` | Шрифт символов. |
| `--uid-code-input-bg`, `--uid-code-input-color` | поверхность, текст | Фон и текст ячейки. |
| `--uid-code-input-border`, `--uid-code-input-border-hover`, `--uid-code-input-border-focus` | рамки темы, акцент | Рамки ячейки. |
| `--uid-code-input-ring` | `--uid-accent` | Цвет кольца фокуса. |
| `--uid-code-input-radius` | `--uid-radius-md` | Скругление ячейки. |

Ряд выровнен по центру контейнера. Светлая и тёмная темы берутся из токенов темы.

Типы: `UidCodeInputProps`.
